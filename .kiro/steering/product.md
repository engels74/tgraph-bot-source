# Product Overview

TGraph Bot is a Discord bot that generates and posts Tautulli graphs to Discord channels. It provides automated insights into Plex Media Server activity through customizable visualizations.

## Core Functionality

- Generates 12+ graph types showing streaming statistics (daily play counts, top users/platforms, resolution distribution, stream types, etc.)
- Automated scheduled graph posting to Discord channels
- Slash commands for manual graph generation and personal statistics
- Web UI for configuration management
- Rate limiting and user privacy controls

## Key Features

- Media type separation (TV shows vs movies)
- Configurable graph appearance (dimensions, colors, palettes, annotations)
- Multi-language support (English, Danish)
- Hot configuration reloading without restart
- Automatic graph file retention management

## Target Users

Plex server administrators who want to share streaming analytics with their Discord community.
